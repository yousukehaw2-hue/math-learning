# 国語まなび（試作）
中学1年生向けの国語学習PWA化前プロトタイプ。東京書籍の学習領域を想定し、独自作成の問題10問を収録。
- 3段階の難易度、読解・漢字・文法・記述、最大5問のセッション
- タブレットのペン・指による手書きキャンバス、キーボード入力
- 記述の模範解答と自己評価ルーブリック
- 選択式の正答率を端末内に保存
- 教科書本文は転載しない
## 実行
ブラウザで index.html を開く。GitHub Pages に公開する場合は、このディレクトリを公開ルートに設定するか別途デプロイ工程を追加する。
