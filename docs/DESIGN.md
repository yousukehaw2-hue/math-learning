# Math Learning — 設計仕様 v1.0
対象: 中学1年・東京書籍『新編 新しい数学1』。iPhone優先の日本語Webアプリ。2026-11-16開始の2学期期末を優先し、3学期末まで拡張する。
## 原則
- 1セッション5問、選択式と数値入力を併用。理解→演習→誤答原因推定→類題→翌日/3日/7日復習。
- 段階的ヒント、数直線・座標グラフ・図形の視覚解説。回答前に正解を漏らさない。
- 正誤は決定論的な検証器で判定。AI生成文を正答判定の唯一の根拠にしない。
- 誤答原因は推定として表示し、確認問題で検証する。
- 学習履歴は初期版では端末内保存。個人情報収集なし。削除/エクスポート可能にする。
- 画面: ホーム、単元、復習、テスト、記録。社会アプリと操作感を揃える。
## 教材
2学期候補: 方程式、比例・反比例、平面図形。3学期候補: 平面図形の続き、空間図形、データの分析。学期配当は学校の進度で変更可能にし、試験範囲は未確認と明記。
## 問題データ
id, unit, skill, prerequisiteSkills, difficulty, prompt, answerType, answer, validator, solutionSteps, hintSteps, misconceptionTags, illustration, reviewPolicy, sourceNote。
- 原則各小単元30〜50問を目標とし、初期リリースは品質検証済み問題を優先。
- 数値可変問題は生成範囲、禁止条件、正解と解説の整合を自動テスト。
- 教科書本文や図版を無断転載せず、学習指導要領と単元に沿ったオリジナル問題。
## 技術
TypeScript + React + Vite のPWAを推奨。localStorage/IndexedDB、単体テスト、GitHub Actions CI。公開先は決定前。Private repoを維持。
## 受け入れ基準
iPhone幅で横スクロールなし。5問完了・再開・復習・記録削除。小数/負数/分数の正答判定。オフライン再訪問。教材検証CI成功。
